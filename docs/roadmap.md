# Roadmap

## v0.1 Experimental

- Publish the Go-transpiler compiler.
- Keep examples compiling in CI.
- Document the implemented subset separately from target-language ideas.
- Ship VS Code syntax and snippets source.
- Include experimental AI context KB commands.

## Next

- Improve diagnostic structure and source locations.
- Add more examples that represent backend tasks.
- Expand semantic checking for scopes, types, and exhaustiveness.
- Add a real test runner behind `lume test`.
- Start a minimal language server after the compiler interface stabilizes.

## Later

- Modules and imports.
- Pipe operator.
- `Result` / `Option` plus propagation.
- Lambdas.
- ADTs and richer pattern matching.
- Formatter.
- Standard library foundations.
