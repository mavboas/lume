# Changelog

## v0.1.0-experimental

- Initial public repository layout.
- Experimental Lume compiler that transpiles to Go.
- CLI commands: `build`, `run`, `tokens`, `ast`, `gen`, and experimental `kb`.
- Examples for functions, math, lists, objects, classes, switch, for, let, and match.
- Semantic diagnostics with AI-readable metadata and repair hints.
- VS Code syntax highlighting, snippets, and file icons source.
